# Проверка релиза PhiStudio 1.0.6

Пакет `com.xpe.mobile`, версия **1.0.6**, versionCode **80**.
Основа — последний проверенный чекпоинт 1.0.6-fixes2.

## Локальная сборка

Среда: Arch ARM64 внутри Android, JDK 17, Android SDK / Build Tools 35,
Gradle 8.9 и AGP 8.7.3.

- Unit-тесты: **825 всего, 810 успешных, 15 пропущенных**, без ошибок.
  Пропуски относятся к отсутствующим необязательным chart fixtures.
- `lintDebug` и `lintRelease`: 0 ошибок, по 24 прежних UnusedResources warning.
- `assembleDebug` и подписанный `assembleRelease` завершены успешно.
- Сертификат совпадает с предыдущими выпусками; SHA-256:
  `0711ce5197d30d09c71630447f8898fa9f195da36387b3f9fe385a084798a9d2`.

`tools/termux-tests.gradle` исключает 23 desktop native-graphics теста в четырёх
классах: Linux ARM64 backend Robolectric для них отсутствует. Они не входят в
число 825 и не объявляются пройденными. GitHub Actions использует полный
desktop-набор без этого профиля перед публикацией APK.

Пример проверки на ARM64:

```sh
ANDROID_HOME=/path/to/android-sdk ./gradlew --no-daemon --offline \
  -Pandroid.aapt2FromMavenOverride=/path/to/arm64/aapt2 \
  -I tools/termux-tests.gradle \
  testDebugUnitTest lintDebug lintRelease assembleDebug assembleRelease
```

## Регрессии

- Сверка GIF-таймлайна с исполненным upstream Rust: 6579 значений совпали точно.
- Воспроизведён и исправлен resize-крэш при обычной экранной клавиатуре.
- Проверены возобновление/перемотка после очистки cache, сохранность рабочего
  PCM, отмена устаревших playback workers и повторное выделение аудиовыхода.
- Line List проверяется на API 33/34 с разной плотностью экрана, размером
  шрифта и высотой окна, включая исходный случай нулевой высоты действий.
- Расширенная проверка Menu: 324 проверки страниц и 48 отдельных окон
  библиотеки/экспорта. Проверяется доступность кнопок и полей после прокрутки.
  Это проверки геометрии framework; полнота текста и OEM-отрисовка не проверяются.
- Получена положительная обратная связь от пользователя reiyanboy:
  прежние сбои при проверке чекпоинта больше не проявлялись.

## Совместимость и ограничения

Численные oracle и CPU-сравнения с prpr проверяют тайминг и данные сцен,
но не доказывают пиксельное совпадение двух приложений. GPU playback и полный
MP4-процесс на физическом устройстве в среде сборки не запускались.
Подробности — [rendering-parity.md](rendering-parity.md).

Проверки на фрагментах внешних чартов и их данные исключены из публичного
проекта; они сохраняются отдельно в локальной среде проверки. В исходниках
оставлены unit-тесты и математические oracle, не содержащие внешних чартов.
Исторические device/refactor probes в `tools/` могут требовать настройки
путей SDK/JDK для конкретной Termux-среды.

Логи, APK, кеши, локальные настройки и ключи хранятся вне исходников.
Данные внешних чартов и их метаданные не входят в публикуемый проект.
Публикуемый архив создаётся через `git archive` из релизного коммита и содержит
исходники, тесты, необходимые ресурсы, лицензии и проверочные инструменты.
