## Area-editor references

Inspected the official documentation and inspector images of these editors:

- [Unity Box Collider 2D](https://docs.unity.com/en-us/engine/6000.3/manual/unity2d/2d-physics/collider-2d/box-collider-2d-reference):
  rectangular geometry has separate position/offset and size properties.
  PhiStudio adds an alternative center/size representation of its native edges.
- [Godot Area2D](https://docs.godotengine.org/en/stable/tutorials/physics/using_area_2d.html):
  an area has an inspector with grouped properties and explicit states. PhiStudio
  keeps its existing Area/Move/Scale/Rotate grouping and exposes field states in
  the scene and field browser.
- [Blender Mask Layers](https://docs.blender.org/manual/en/latest/movie_clip/masking/sidebar.html#mask-layers):
  the selected mask appears in a compact list with adjacent add/remove controls.
  PhiStudio highlights the current field in its browser and exposes deletion in
  the property header. The [official inspector image](https://docs.blender.org/manual/en/latest/_images/movie-clip_masking_sidebar_mask-layer-panel.png)
  was inspected along with Godot's area inspector and Unity's collider tools.

These are interaction/design references. No external editor code or graphics are
copied into the app. Their geometry models, animation formats and blending rules
are not substitutes for Phigros's native block-area behavior.

## Usability changes

The accepted layout, shared control sizes and timeline/preview gestures from
checkpoint 6 remain: preview left, vertical timeline right, properties below,
32 dp footer with equal-width mode/Menu buttons.

- Delete field is immediately accessible beside Apply/Reset, including when the
  property panel is collapsed. In an animation tab the same button says Delete
  key. It is disabled without a valid selection. Undo restores either operation.
- Fields supports search, All / At playhead / Normal / Subtract filters, a
  selected-row highlight, phase state, key count and lifetime. Results sort by
  appearance without changing the raw chart order or indices. At playhead is a
  labelled time snapshot, so playback cannot move a row underneath a finger.
  Picking a result reveals its timeline lane and seeks to its appearance time.
  Stale rows cannot select a different field after an external deletion.
- The field browser adapts to available dialog height. With a landscape keyboard
  it prioritizes search/results; filters and count return as space becomes
  available. The keyboard's Done action hides it without closing the browser.
- Edges ⇄ / Center/size ⇄ switches geometry representation. Valid pending values
  survive this display change; it creates no history entry. Only edited numeric
  values are rewritten. Negative sizes, offscreen coordinates, unedited raw
  precision and extension properties remain supported. Apply commits the draft
  as one ordinary Undo step. Reset discards it.
- Scale/Rotate anchor presets provide nine screen anchors in a compact 3x3
  popup. They populate the existing percentage fields as a pending edit. Screen
  Y points up: the top row is 100%, the middle is 50%, the bottom is 0%.
  Custom anchors outside the screen remain available through numeric input.
- Previous/next key navigate chronologically and seek to that key's time while
  retaining raw key identity. Unavailable navigation and copy actions disable.
- Invalid numbers and inverted lifetime pairs identify the offending inputs.
  Invalid drafts remain editable and do not change the native document.
- Returning after Undo in another mode drops a draft whose target field was
  removed/replaced. It cannot preview over another field or index an empty list.
  Drafts of unchanged fields still survive ordinary mode switches.

## Selection guides

Guides are on by default and can be toggled in More → Guides without applying or
discarding a pending form. The guide layer does not accept touches and sits above
both the GPU TextureView and the Canvas preview. It is invalidated as preview
frames advance, including during playback.

The selected field's animated contour and center use the renderer's native f32
geometry. A yellow marker shows the selected Scale/Rotate key's screen anchor.
An in-preview label identifies the field and Active / Ready / Inactive / Outside
lifetime state. Outside its lifetime the contour is dashed. Guide geometry is
available then for editing, but the normal renderer still returns no field.

Projection uses the same fitted player viewport at 3:2, 16:9 and other configured
aspects. Each contour edge is clipped before reaching Canvas, so large/offscreen
coordinates cannot create huge Canvas paths. Enclosing offscreen rectangles do
not acquire fictitious borders along the viewport. Guides are editor-only; they
do not enter Preview, Playtest, exported video or saved chart data.
