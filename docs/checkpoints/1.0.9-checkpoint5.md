## Navigation and mobile workspace

Two equal-width, 48 dp bottom buttons replace the four old tabs. The left button
shows the active mode and opens Event, Storyboard, Shaders and Noise Field. Menu
is on the right; Back from Menu returns to the previous mode. Shader mode retains
its session and the event/storyboard editors retain their original behavior.

Noise Field has a horizontally scrollable toolbar, a live GPU/Canvas chart
preview, timeline and scrolling inspector. The inspector remains usable when the
keyboard reduces window height: secondary headers/status collapse while input
rows and Apply/Reset retain their touch sizes. A tall/narrow window stacks the
inspector beneath the preview. English and Chinese resources support in-place
language switching without replacing focused draft controls.

The inspector includes every native `blockAreaList` authoring property:

- Bottom-left/top-right screen percentages, with Y up, and subtraction.
- Appear, enable, disable and disappear times. Native validation retains only the
  original pair constraints: appear <= disappear, enable <= disable.
- Move X/Y, Scale X/Y and Rotation keyframes with exact native times.
- Screen-space scale/rotation anchors and independent outgoing X/Y easing
  (rotation uses a single easing). All 15 native curves have graph previews.
- Offscreen/negative coordinates, zero/negative scales, negative times, rotations
  beyond one turn, unsorted input keys and duplicate timestamps are retained.

The native renderer still determines fade, overlap parity, infection and audio
filter behavior. These are not invented per-field properties. Preview editing
handles do not act as infected gameplay contacts; Menu -> Playtest exercises the
existing touch and audio behavior.

## Authoring and persistence

Add field/key uses the playhead. The searchable field chooser shows names, types
and lifetimes. A key chooser sorts display order while retaining each original
array index. Duplicate/copy/paste and moving a whole field shift all native second
times together. Full-screen bounds, beat/second display, beat-subdivision snapping,
looping, guide visibility, timeline Fit/zoom/pan and precise seeking are included.
Beat display converts through the chart BPM map; negative-time authoring extends
the first BPM rather than clamping it like the playback clock.

Dragging a base corner/center edits its bounds; Move handles edit the selected
key position and Scale/Rotate handles edit its anchor. The animated outline is
separate from the base guide. Phase/key markers can be dragged in the timeline.
Guide segments are clipped before Canvas tessellation for extreme imported
geometry. A cancelled gesture, extra finger, resize or activity pause discards its
preview. A completed drag creates one shared undo entry.

Valid form drafts and gestures supply temporary immutable field snapshots to the
same preview renderer used by the shader editor; the chart is not mutated every
frame. Apply, Save or leaving the mode commits valid forms. Invalid input keeps
its text and prevents navigation until corrected or reset. Draft Undo resets the
form; committed Undo/Redo shares the chart history, dirty tracking, project save,
autosave and export. Hardware editing shortcuts route to the active field editor.
Changing the chart disposes its previous field session. Unedited JSON properties,
including unknown nested metadata and exact numeric precision, are preserved.
An optional `phiStudioName` field stores the editor label and is ignored by the
native renderer.

## Validation

Domain tests cover all 15 outgoing curves, native lifetime rules, key identity and
duplicate times, metadata preservation, scoped history, shifted copies, undoing
field/key deletions, and package save/reimport of an edited Desultory Signals. The
real-chart test preserves the other 159 fields, 2026 notes and the audio resource.

Robolectric UI tests exercise the equal footer, all four menu choices, navigation,
live form drafts, invalid values, raw precision, all transform controls, negative
beat conversion with BPM changes, single-transaction drags, second-finger/resize/
background cancellation, short keyboard windows, language switching, hardware
shortcuts and chart replacement. Existing shader/workbench tests are updated for
the footer and retained. The full ARM64 suite includes the supplied Micrology and
Desultory regressions; desktop graphics tests excluded by the host profile are not
counted as passed.

No ADB device is connected. On-phone visual/touch/keyboard verification remains
a device check; Robolectric and host tests do not verify Android HWUI delivery.
