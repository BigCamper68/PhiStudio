## Field grids and lower navigation

Each selected noise field has a vertical grid containing Area (appearance to
disappearance), Active (enable to disable), Move, Scale and Rotate. Keys retain
their original JSON indices and outgoing native easing. Selecting a key in any
lane opens that channel's existing properties. Empty lanes remain available;
the touch sizes, baseline, pan/hold/resume, pinch, horizontal header scrolling,
snap and S/E resizing use the existing editor conventions.

The lower-left space now contains previous field, field selector, next field,
All fields / Field grid, and Locate. Field selection through the browser or
arrows preserves the playhead. Locate explicitly seeks to appearance. The
preview continues to compose all fields; the selected guide is an editing aid.
The overview assigns one independent lifetime lane to each raw field, including
simultaneous Normal/Subtract fields. Tapping a block opens its own grid. Neither
selection nor display order rewrites or rearranges chart data.

The whole lower row, including the two equal-width mode/Menu buttons, is 34 dp
high (previously 32 dp). Other property buttons retain their existing 32 dp
height. The navigation is hidden outside Noise Field mode and does not cover
properties, the grid or the mode/Menu hit areas.

## Immediate properties and shared Undo/Redo

Area, Move, Scale and Rotate save each valid change immediately to the chart's
shared history and existing project autosave path. Apply and Reset draft were
removed. Input views stay attached while typing, retaining selection, focus,
keyboard and locale bindings. Typing continuously in one control coalesces into
one undo command; focus changes, another control, another chart command or a
new color-picker session start a new operation. An anchor preset changes both
coordinates in one undo command. Gestures retain their single commit/cancel
behavior.

Invalid numbers/time pairs stay highlighted, retaining the last valid value.
Other valid properties continue to save even while one input is invalid. Undo
and Redo restore immutable field snapshots with original raw metadata and
selection. Coalescing checks the shared history's actual latest command; it
cannot absorb another editor operation or cross an Undo/Redo branch.

## RGB field color

Area has the existing RGB palette, with immediate preview/save and an OK button
to close it. One open palette is one undo operation. Native red restores the
standard Phigros material. RGB applies through the shared renderer in every
preview, editor underlay, Playtest and video export. The editor overview blocks
and selected field outline also identify custom colors.

Native `blockAreaList` has no documented RGB field in the supplied chart or the
checked Phira Pro native-area parser. This checkpoint defines a **PhiStudio
extension**, independently of RPE line colors:

```json
"phiStudioColor": [40, 180, 255]
```

It is an optional field property containing three integer bytes 0–255. Missing
or malformed values render in native red `#FF5454`; malformed/unknown JSON is
retained unless explicitly edited. Native red removes this property. Color is
static per field; there is no color-keyframe channel. Other players may ignore
the extension. Duplication, copy/paste, autosave, reload and package export
preserve it. Native charts are not rewritten just by opening the color control.

The original Phigros shader assets and native geometry/coverage passes are
unchanged. Charts without custom color use the original GPU path and allocate
no palette. For colored frames an independent low-resolution ownership map
chooses colors only from regions surviving native Normal/Subtract composition.
Later raw fields of the surviving type own overlapping color. Nearest visible
owners extend through carved holes and into glow, keeping a hole's own color
from leaking into its rim. Active and inactive ownership are separate; hover/touch effects use inactive
RGB where no active material is visible, including the ready phase. A GPU
pass uses the extracted native Compose displacement equations to warp active
colors with the corresponding mask. The scene snapshot is never multiplied by
the field color. Material variants transfer hue/saturation/brightness to fill,
edge, glow, noise and touch materials; neutral colors keep neutral sparks.
Coverage, phase opacity, touch blocking and audio filtering remain native.

The palette is cached by geometry, state, size/aspect and RGB. Time changes
warp it on the GPU without CPU image readback; the same paused frame reuses its
upload/warp. Palette programs/textures are created only when needed. Colored
materials use 11 fragment texture units, sharing the two native displacement
samplers' identical texture.

  against supplied Desultory Signals over 48 samples/42 distinct frames.
- Independent float32 geometry oracle, production external-texture compositor,
  Android lint, i18n/locale validation, APK signing/alignment and source/patch
  integrity checks. Final counts and hashes are in `checkpoint.json`.

tests and reports missing optional-fixture skips separately. Mesa tests execute
