# PhiStudio 1.0.9 checkpoint 2

Based on checkpoint 1, `bb5bab430494e6a953c107236d166ab00e096f1a`.
The Micrology Playtest clipping fix is retained.

## Native noise fields

Official Phigros `blockAreaList` is imported into the chart model and preserved
when saving projects and exporting packages, including unknown per-area fields.
Field event times are seconds, independent of judge-line BPM. Native scale and
rotation anchors, the 101-sample easing tables, ready/active/disabled phases and
overlapping subtraction areas are evaluated at the current chart time.

Preview, Playtest and video export share an EGL compositor. It renders disabled
fields above the background and below notes, then renders active fields and touch
effects above gameplay and HUD. Native material values, textures, pixelation,
edge/glow passes, subtraction thresholds and the ten touch slots are retained.
Playtest blocks infected contacts until release, including stationary contacts
when a field activates, while allowing other fingers to continue judging notes.
Pause and Retry clear contacts. Seeking back into an effect also requests a fresh
frame when a previously hidden GPU frame is still draining.

## Reference and port

The reference is the published Phigros 4.0.1 extraction and decompiled behavior in
[CHCAT-Docs at 054fcfd](https://github.com/CHCAT1320/CHCAT-Docs/tree/054fcfdddc4ddf66b1bbecc45df0d5264e3d3852/knowladge/phigros).
The compiled GLES3 programs are adapted to PhiStudio's GLES2 context without
rewriting their shader arithmetic. Texture exports with corrected channel bits
come from [Phira-Pro at b67e5e8](https://github.com/Phira-Pro/Phira-Pro/tree/b67e5e845b58e3cf89d674e782a9b3bd0f5e8af8/assets/blockarea).
Asset hashes, source revisions and attribution accompany the bundled resources.

This is a port from extracted shaders and published decompilation, not access to
the complete original Unity project. Unity's global `_Time` is replaced by chart
time so pause, seeking and exported frames remain deterministic. This checkpoint
covers rendering and touch rejection; Unity's audio low-pass effect is outside
the rendering port. The alternate RPE Next block-area schema is not supported.

## Validation

- Synthetic tests cover lifecycle boundaries, easing, anchored transforms, reverse
  seeking, zero/negative scales, duplicate keys, subtraction and inset hit tests,
  persistent touch infection, multitouch, hold release, pause and GPU routing.
- The optional real-chart test imports Desultory Signals AT: 160 noise fields,
  including 18 subtraction fields, and 2,026 notes. It checks 27,000 frames across
  3:2, 16:9 and 21:9, saves/reloads the chart and exports/reimports its package.
  Enable it with `PHISTUDIO_NOISE_FIELD_CHART=/path/to/Desultory_Signals_AT.pez.zip`.
- An independent Python float32 evaluator compares the native equations with
  production Java at keyframes, lifecycle boundaries and intermediate times.
- A JNI host adapter executes the production Java renderer on Mesa GLES. Its
  GLES2 shader output is compared against the original GLES3 shader arithmetic
  at 42 distinct frames in three viewport sizes, including a held touch. Both
  runs share geometry, textures and compositor configuration. This establishes
  shader adaptation equivalence for those samples, not full-game equivalence.
- ARM64 tests use `-I tools/termux-tests.gradle`; excluded desktop native graphics
  tests are not counted as passed. The Micrology real-chart regression remains
  enabled during the full checkpoint test run.

No physical Android device was connected. Android SurfaceTexture delivery and a
hardware MediaCodec MP4 export require a device check. Installation should update
checkpoint 1: the application ID and signing certificate are unchanged, while
versionCode advances to 97. Build with `-PcheckpointBuild=true`.
