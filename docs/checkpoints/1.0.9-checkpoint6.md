# PhiStudio 1.0.9 checkpoint 6

Based on checkpoint 5, `2b9f328407fef32cd19691ceeb6858206d4d4ec6`.
VersionCode 101, versionName `1.0.9-checkpoint6`, application ID
`com.xpe.mobile.checkpoint`, existing checkpoint certificate.

## Noise Field follows the existing editor

The separate horizontal timeline, right-side inspector and preview geometry
handles from checkpoint 5 are removed. Noise Field now copies the Shaders
workspace: preview left (60%), vertical beat/event grid right (40%), compact
properties below both. Panel heights (88 dp / expanded / collapsed), the 48 dp
toolbar and 38 dp toolbar buttons are shared with Shaders. Other buttons are 32 dp;
numeric rows use the existing 40 dp / 12 sp format. The bottom mode selector and
Menu remain equal-width and use a reduced 32 dp footer height.

`SceneEditorControls` and `SceneEditorLayout` contain the existing shader control
and layout code used by both editors. `ScenePreviewPan` contains the original
shader preview hold/pan handler, also used by both Canvas and GPU previews.
Easing uses the existing `EasingSelector` with the native 15-curve list instead
of a separate button/graph implementation. Other editors retain their 29 curves.

The upper toolbar contains Play/Pause, Loop, units (beats by default), Add Field
or Add Key, Fields, Undo/Redo, Save and More, plus the same complete audio seek
track as Shaders. The bottom row contains Area/Move/Scale/Rotate, Apply/Reset,
status, Expand/Compact and collapse controls.

## Vertical timeline and touch behavior

The Noise Field timeline uses the existing row grid, beat-number ruler, baseline,
block rendering, selections and S/E handles. Normal and Subtract lanes display
all field lifetimes. Active displays the selected field's enable/disable range.
Move/Scale/Rotate display outgoing key intervals and native easing curves; the
last key is a single timestamp with a native-style start handle.

Pointer routing follows ShaderEditorTimeline: tap selects, dragging a block body
or empty area pans time, selected S/E handles resize times, horizontal header
movement scrolls lanes and a two-finger pinch zooms. Timeline scroll speed,
event scroll speed, subdivisions, curve visibility and tap-to-seek settings are
shared with the editor. Holding pauses playback/audio and releasing resumes it.
There is no separate preview geometry gesture system.

A handle gesture previews immutable snapshots and commits one shared Undo entry
on release. Cancel, another finger, resize, mode change and backgrounding discard
the unfinished handle edit. Redraws do not accumulate the movement delta.

Forms use normal editor semantics: Apply commits, Reset discards, Undo/Redo acts
on the document. Switching modes retains uncommitted/invalid text and does not
block navigation. Selecting another item, editing a handle, changing units or
using a document action rebuilds properties from the document, as in Shaders.
Save applies a valid pending form. Beat fields accept the existing decimal and
whole:numerator/denominator notation.

All native field data and checkpoint 5 copy/key/save functionality remain:
four lifetime times, bounds, subtraction, X/Y movement/scales, anchors, rotation,
15 native easings, negative/offscreen values, duplicate/unsorted keys, extension
metadata and exact precision of unedited properties. Times are still stored in
native seconds. The existing infection/audio behavior belongs to Playtest.

## Validation

UI tests compare Noise Field geometry directly against Shaders at 800x360,
1200x700, 1920x1080 and keyboard-reduced 800x240. They compare toolbar button size,
font, seek width, compact/expanded property heights and full first-row visibility.
Gesture tests compare preview pan direction/speed, GPU/Canvas forwarding,
playback hold/resume, grid baseline/spacing, body pan, S/E edits, event-speed
settings, empty-tap selection/tap-to-seek, pinch zoom, cancellation and Undo.

Tests also retain native data preservation, all transform/easing controls,
negative time/BPM conversion, language switching, shortcuts, chart scoping and
editing/saving/reimporting the supplied Desultory Signals package. The full host
suite includes both supplied charts. ARM64-incompatible desktop graphics tests
excluded by the host profile are not counted as passed.

No ADB device is connected. The checks use Android layout/gesture tests and host
regressions; they do not claim a physical-device screenshot or HWUI verification.
