## Project discovery and opening

Displaying the library previously walked every resource in every indexed
workspace. Each entry incurred several filesystem queries and repeated canonical
path resolution. Opening also scanned asset contents to rediscover the chart,
parsed JSON candidates, discarded the chosen tree and parsed the chosen chart
again. Large charts and packages with many resources amplified this work.

Indexed library rows now check just the indexed chart's path components, regular
file status, size and JSON header. Other resources are checked when opening the
project. Unindexed/recoverable workspaces still receive full inspection. A damaged
indexed workspace cannot abort discovery of the other projects.

Full opening obtains attributes once per entry, keeps deterministic sorted
depth-first inventory, and retains entry count, individual/total size, unsupported
entry and symbolic-link checks. A single supported manifest chart reference is
loaded directly and its parsed tree is reused. Packages without a unique usable
hint still use structural chart discovery, including ambiguity checks, official
Phigros/PEC conversion, extension-independent detection and BOM handling. The
single-JSON fallback also reuses its parsed tree; multiple candidates keep the
bounded-memory discovery path. Binary resources receive a cheap prefix check
before the bounded PEC text probe.

Opening always reads current manifests and chart content, so edited data is not
hidden behind a stale model cache. Automatic restoration of the last project uses
the same faster loader; that work can also be part of the initial scanning dialog.

## Playtest volume buttons

Playtest previously paused whenever its window lost focus. Android's system
volume panel can take focus while the activity remains resumed, so either volume
button could unexpectedly pause a chart.

Transient window focus no longer pauses Playtest or clears held contacts.
Volume keys continue through the normal Android path. Real activity backgrounding
still calls the existing pause path, which pauses audio and clears contacts and
the noise-field audio filter. Explicit pause, Back, Retry and exit retain their
existing behavior.

## Validation

Regression tests cover direct manifest selection and fallback, conflicting
manifests, unsupported explicit formats, BOM/extension-independent discovery,
reopening edited charts and changed manifests, quick header checks versus full
resource checks, symbolic chart/resource paths, exact inventory limits/order and
individual/total size limits. PEC probing includes commands beyond the first
buffered block and excessive leading whitespace.

Playtest UI tests cover volume up/down plus focus loss during a hold, countdown
continuation, and an actual `MainActivity.onPause` pausing playback. The full
ARM64 suite also includes Micrology and Desultory Signals regressions. Desktop
native-graphics tests excluded by `tools/termux-tests.gradle` are not counted as
passed.

No ADB device was connected. Physical volume-panel behavior and elapsed Android
dialog times still require a device check.
