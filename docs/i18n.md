# Internationalization

`languages/en.json` is the complete source of Android string resources. Add a
`languages/<canonical-BCP47-tag>.json` file to add a language; no Java, manifest,
or Gradle edits are needed. For example:

```json
{
  "meta": {"name": "日本語", "author": "Contributor"},
  "strings": {"settings_title": "設定"},
  "plurals": {"controls_selection_count": {"other": "%1$d selected"}},
  "arrays": {"note_sides": ["上", "下"]}
}
```

Translations may omit individual strings and entire arrays/plurals. Omitted
entries are not copied into the translated XML: Android chooses compatible
locale resources and ultimately the English default. If an array is provided,
its length and semantic order must match English. A plural requires `other`;
other quantities may follow the language's own rules. The maintained Simplified
Chinese pack (`zh-CN.json`) covers every translatable entry, including help,
validation messages, dialogs, event names, easing choices and HUD choices.
`tools/i18n/verify_translations.py` checks that coverage to prevent new English
fallbacks. Other language packs may remain partial.

Keep indexed format arguments (`%1$s`, `%2$d`, etc.) and their types. Reordering
and repeating arguments is allowed. `%%` is a percent sign. JSON strings contain
ordinary Unicode and JSON escapes, not Android XML escapes. The compiler handles
XML characters, apostrophes, quotes, backslashes, whitespace and resource-like
prefixes. Do not add HTML/Android markup to translation values.

Only English can define `options`. Allowed options are `formatted`,
`translatable`, and `preserve` (a list of literal protected tokens). Unknown
keys/options, duplicate JSON members, malformed locale names, incompatible
arguments, wrong array lengths and missing protected tokens fail the build.
`meta.name` is required and appears as the language's native display name.

The build-only compiler lives in `buildSrc`. Each variant registers a separate
cacheable generator with AGP's generated-resource API. English becomes `values/`;
other tags become BCP 47 directories such as `values-b+zh+CN/`. The generator
validates everything before replacing its own output directory. It emits sorted,
UTF-8 XML and the `i18n_locale_codes` / `i18n_locale_names` registry arrays. Deleted
packs cannot leave old resources in a variant's output. Never edit generated
XML or introduce source string XML alongside these packs; `validateI18n` checks
all Android source sets. AGP generates LocaleConfig from these resources.
Language splitting is disabled for app bundles so offline switching has every pack.

## Runtime ownership

`LanguageController` is Activity-owned and initialized during context attachment,
before any editor views are constructed. On API 33+ the platform `LocaleManager`
owns the choice and synchronizes it with Android Settings. A previous API 26–32
preference migrates once when upgrading; subsequent system choices take priority.
On API 26–32 an independent `phistudio_language` preference stores the choice.
The empty choice means system default. Both paths obtain fresh resources using
`createConfigurationContext`, retaining the system locale list for native
fallback. Neither `Locale.setDefault`, deprecated global resource updates,
AppCompat, nor Activity recreation is used.

The Activity handles `locale|layoutDirection` configuration changes and explicitly
propagates `relocalizeUi()`. Canvas owners invalidate their resource caches;
panels update existing labels/actions; dialog bindings update existing windows.
Resource IDs and formatting suppliers live with their views, including detached
panel navigation pages. There is no global event bus or runtime translation map.
Never rebuild a stateful form to change language. Text, cursor, focus, checked
state, selected index and scroll position belong to the original widgets.

Language selection is separate from `EditorSettings` and its Apply action. It
does not issue editor commands, save/reload charts or projects, touch undo/redo,
seek playback, reset shader documents or cancel video export. Known package and
workspace errors are mapped from domain codes in the presentation layer; technical
details remain visible. Domain/model code has no new Android resource dependency.

User metadata, authored storyboard text, chart defaults, JSON keys, beat/numeric
protocols, GLSL, shader identifiers, paths and filenames remain data. GUI fallbacks
such as an empty toolbar title are separate resource-backed labels. The target
game's `AUTOPLAY` rendering remains fixed. Product names such as PhiStudio, Phira
and Phigros, and the four note names Tap, Drag, Flick and Hold, remain unchanged.
Event names and actions are translated only in the presentation layer.
Process-wide numeric locales are not
changed; project timestamps explicitly use the current app locale.

Full RTL layout adaptation is a separate task: chart/timeline coordinates have
fixed spatial meaning and should not be mirrored automatically. Debug builds
enable Android's expanded and RTL pseudo locales; release LocaleConfig excludes
them.

## Verification

```text
gradlew -p buildSrc test
python tools/i18n/verify_translations.py
gradlew validateI18n testDebugUnitTest lintDebug assembleDebug generateReleaseLocaleConfig
python tools/i18n/verify_locale_config.py
```

CI runs these checks. Generator tests cover strict JSON, duplicate members,
contracts, partial plurals, whole-array fallback, protected tokens and deterministic
escaping. Resource/UI tests cover APIs 26, 32 and 33: native resources and themed
contexts, system default, persistence, retained form drafts/selection/focus/scroll,
unchanged chart and shader data, Settings isolation and existing video dialogs.
These are Robolectric tests; device-specific configuration delivery, IME behavior
and visual expansion still benefit from real-device testing.

For an optional local package regression, set `PHISTUDIO_TEST_PACKAGE` to a supplied
chart archive and run `LanguageSwitchTest` (force a test rerun when changing the
environment variable). The test imports into a temporary workspace, verifies
audio/illustration bytes, checks data and preview line positions across language
switches, and saves/reopens the working copy. The source archive remains unchanged
and is not committed as a fixture.
